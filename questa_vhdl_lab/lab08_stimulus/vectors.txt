# vectors.txt -- LAB 08 : file based test vectors
#---------------------------------------------------------------------
# One vector per line, all values in hexadecimal:
#
#    ADDR   DATA   EXPECTED   OP
#
#   ADDR     4 bit address of the register file
#   DATA     8 bit value that is written to that address
#            (00 and ignored when OP = R)
#   EXPECTED 8 bit value that the read back must give
#   OP       W = write DATA to ADDR and read it back
#            R = read only, the register must still hold EXPECTED
#
# The first line of the file must be the line "AA 3F" shape :
# address first, data second.
#
# The reader in tb_stimulus.vhd uses "hread", and hread only works on
# BIT_VECTOR -- that is why the DUT data path uses bit_vector.
#=====================================================================
