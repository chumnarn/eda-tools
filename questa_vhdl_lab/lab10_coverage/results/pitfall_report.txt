 PITFALL 2 : std.env.finish kills the whole 'vsim -c' session
--------------------------------------------------------------------
command : vsim -c -coverage work.tb_alu_fsm_finish -do "run -all; coverage save ..."
without -onfinish stop : the UCDB was created = 0   (expected: no)
   -> std.env.finish ended the session, 'coverage save' never ran
with    -onfinish stop : the UCDB was created = 1   (expected: yes)
   -> the simulation only stops, the session stays alive
