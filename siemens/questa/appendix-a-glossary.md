## 1. ศัพท์ของเครื่องมือจำลอง

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย |
|---|---|---|
| ไลบรารี | library | โฟลเดอร์ที่เก็บ design unit ที่คอมไพล์แล้ว |
| ไลบรารีทำงาน | working library | ไลบรารีที่เก็บโค้ดของเราและเปลี่ยนแปลงได้ตลอด |
| ไลบรารีทรัพยากร | resource library | ไลบรารีที่คงที่ ใช้เป็นแหล่งของ component เช่น model ของผู้ผลิตชิป |
| หน่วยการออกแบบ | design unit | ส่วนหนึ่งของงานออกแบบที่คอมไพล์แยกกันได้ เช่น entity, architecture, package, configuration |
| ตัวเลือกการออกแบบ | design option | ตัวเลือกที่กำหนดวิธีการทำงานของเครื่องมือ เช่น `+acc` |
| การเพิ่มประสิทธิภาพ | optimization | กระบวนการที่เครื่องมือทำให้ simulation เร็วขึ้น โดยอาจตัดรายละเอียดทิ้ง |
| เครื่องมือเพิ่มประสิทธิภาพ | `vopt` | คำสั่งที่ทำหน้าที่ optimize design |
| ขอบเขต | scope | ชื่อเต็มของวัตถุที่ระบุตำแหน่งใน hierarchy เช่น `tb_x/dut/sig` |
| ตัวตรวจ | probe | จุดที่ติดตามค่าของสัญญาณในช่วงเวลาที่กำหนด |
| ลำดับชั้น | hierarchy | โครงสร้างของ instance ที่ซ้อนกัน |
| ระดับบนสุด | top level | entity หรือ configuration ที่ถูกโหลดเข้าสู่ simulator |
| ตัวอย่าง | instance | การเรียก entity หนึ่งไปอยู่ภายใน entity อีกตัว |
| ชั้นที่ | level | ความลึกของ instance ใน hierarchy |
| บันทึกถอดความ | transcript | ไฟล์ที่เก็บคำสั่งทุกคำสั่งและข้อความทั้งหมดของเครื่องมือ |
| ชุดข้อมูลคลื่น | waveform dataset | ข้อมูลที่บันทึกค่าของสัญญาณทั้งหมด |
| ไฟล์ WLF | WLF file | รูปแบบไฟล์ waveform ของ Questa |
| ไฟล์ VCD | VCD file | รูปแบบไฟล์ waveform มาตรฐานเปิด |
| ไฟล์ GHW | GHW file | รูปแบบไฟล์ waveform ของ GHDL |
| ตัวชี้ตำแหน่ง | cursor | เส้นที่ใช้ชี้เวลาในหน้าต่าง Wave |
| การวัดเวลา | measure | การหาระยะเวลาระหว่างสองจุดในหน้าต่าง Wave |
| กลุ่มสัญญาณ | group | การจัดสัญญาณหลายตัวเข้าด้วยกันเพื่อให้อ่านง่าย |
| เส้นคั่น | divider | เส้นแยกกลุ่มสัญญาณในหน้าต่าง Wave |
| โหมดบรรทัดคำสั่ง | command line mode | โหมดที่ไม่เปิดหน้าต่างกราฟิก ใช้ `-c` |
| จุดหยุด | breakpoint | จุดที่สั่งให้ simulation หยุด |
| การทำขั้นตอน | step | การเดินโค้ดทีละขั้นตอน |
| บังคับค่า | force | การกำหนดค่าสัญญาณให้คงอยู่จนกว่าจะคืนการขับ |
| คืนการขับ | release | คืนการควบคุมสัญญาณให้ driver เดิม |
| ฝังค่า | deposit | การกำหนดค่าสัญญาณเฉพาะเวลาปัจจุบัน |

## 2. ศัพท์ของภาษา VHDL

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย |
|---|---|---|
| หน่วยบริบท | context clause | ส่วนที่ประกาศ `library` และ `use` มีผลกับ design unit ถัดไปหนึ่งหน่วย |
| สถาปัตยกรรม | architecture | ส่วนที่อธิบายการทำงานของ entity |
| การกำหนดค่า | configuration | วิธีระบุว่า entity ใดผูกกับ architecture ใด |
| การทำให้เป็นรูปแบบ | elaboration | ขั้นตอนที่เครื่องมือสร้าง design ที่จำลองได้จาก design unit |
| ตัวกำหนดทั่วไป | generic | พารามิเตอร์ที่กำหนดค่าได้ตอนสร้าง instance |
| แผนที่พอร์ต | port map | การผูกสัญญาณภายนอกกับพอร์ตของ instance |
| แผนที่ generic | generic map | การกำหนดค่า generic ตอนสร้าง instance |
| สัญญาณ | signal | ตัวแปรที่มี driver และมีประวัติค่า |
| ตัวแปร | variable | ตัวแปรที่อ่านค่าได้ทันทีและมีชีวิตอยู่ใน process |
| ไดรเวอร์ | driver | แหล่งที่กำหนดค่าของสัญญาณ |
| สัญญาณแบบ resolved | resolved signal | สัญญาณที่รวมค่าจากหลาย driver ด้วยกฎของตาราง truth |
| วงจรเดลตา | delta cycle | รอบการอัปเดตสัญญาณที่มีเวลาเป็นศูนย์ใน VHDL |
| คิวเหตุการณ์ | event queue | โครงสร้างที่เก็บเหตุการณ์ที่รอการทำงาน |
| ความละเอียดเวลา | time resolution | หน่วยเวลาต่ำสุดที่ simulator แยกแยะได้ |
| หน่วยเวลา | time unit | หน่วยของเวลา เช่น `ns` `us` `fs` |
| การรอเหตุการณ์ | wait until | รอจนกว่าเหตุการณ์ที่ทำให้เงื่อนไขเป็นจริงเกิดขึ้น |
| ขอบขึ้น | rising edge | จุดที่สัญญาณเปลี่ยนจาก 0 เป็น 1 |
| ขอบลง | falling edge | จุดที่สัญญาณเปลี่ยนจาก 1 เป็น 0 |
| ความรุนแรง | severity | ระดับความสำคัญของข้อความ `report` และ `assert` |
| การยืนยัน | assertion | คำสั่งตรวจเงื่อนไขและรายงานเมื่อไม่ผ่าน |
| ค่าที่ไม่รู้ค่า | unknown value | ค่า `X` หรือ `U` ของ `std_logic` |
| ค่าความต้านทานสูง | high impedance | ค่า `Z` ของ `std_logic` |

## 3. ศัพท์ของการทดสอบ

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย |
|---|---|---|
| โมเดลทอง | golden model | แบบจำลองอ้างอิงที่ใช้คำนวณค่าที่ถูกต้องเพื่อเทียบกับ DUT |
| testbench ตรวจผลเอง | self-checking testbench | testbench ที่ตรวจผลและสรุปผลเองโดยไม่ต้องให้คนดู waveform |
| เครื่องป้องกันเวลา | watchdog | ส่วนของ testbench ที่ยิงเตือนเมื่อการทดสอบใช้เวลานานผิดปกติ |
| ตัวทดสอบเชิงลบ | negative test | เคสที่ตั้งใจให้ล้มเหลว เพื่อพิสูจน์ว่าการตรวจสอบทำงานจริง |
| เคสขอบเขต | corner case | กรณีที่อยู่ที่ขอบเขตของช่วงค่าที่ออกแบบไว้ |
| เครื่องหมายยืนยัน | marker | ข้อความที่พิมพ์เมื่อการทดสอบผ่านหรือไม่ผ่าน |
| การครอบคลุม | coverage | สัดส่วนของพฤติกรรมที่ถูกทดสอบ |
| พฤติกรรมที่ต้องการ | required behavior | สเปกของสิ่งที่ออกแบบต้องทำได้ |
| การกระตุ้น | stimulus | สัญญาณหรือค่าที่ป้อนเข้าไปยัง DUT |
| การบังคับให้เป็นแบบสุ่ม | constrained random | การสุ่ม stimulus ภายใต้ข้อจำกัดที่กำหนดไว้ |
| พอร์ตที่ต้องตรวจ | cover point | จุดในกรอบการครอบคลุมที่ต้องการเก็บค่า |
| รหัสจบการทำงาน | exit code | ตัวเลขที่ process คืนให้ระบบปฏิบัติการ |
| การตรวจสอบอัตโนมัติ | continuous integration (CI) | ระบบที่รันการทดสอบอัตโนมัติทุกครั้งที่มีการเปลี่ยนแปลงโค้ด |

## 4. ศัพท์ของการสังเคราะห์

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย |
|---|---|---|
| ส่วนที่สังเคราะห์ได้ | synthesis subset | ส่วนของภาษาที่เครื่องมือสังเคราะห์เข้าใจ |
| รายการต่อสาย | netlist | คำอธิบายวงจรที่ได้หลังสังเคราะห์ ในรูปของ primitive และการเชื่อมต่อ |
| กล่องดำ | black box | โมดูลที่ไม่ทราบโครงสร้างภายใน ใช้แบบมีแต่พอร์ต |
| เส้นทางการสังเคราะห์ | synthesis path | ขั้นตอนการแปลง RTL เป็น netlist |
| การเปรียบเทียบระดับสัญญาณ | gate-level simulation | การจำลองด้วย netlist ระดับ gate |
| การจำลองระดับ RTL | RTL simulation | การจำลองด้วยโค้ด RTL ก่อนสังเคราะห์ |
| ระดับความเชื่อมั่น | confidence level | ระดับที่ผลการตรวจสอบรองรับได้ |
