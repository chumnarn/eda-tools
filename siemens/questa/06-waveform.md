## 1. เปิดหน้าต่าง Wave และเพิ่มสัญญาณ

### 1.1 เปิดหน้าต่าง Wave

เลือก **View → Wave** หรือพิมพ์ที่ prompt

```text
view wave
```

หน้าต่าง Wave จะเปิดทางด้านขวาของหน้าต่างหลัก

### 1.2 เพิ่มสัญญาณ

**วิธีที่ 1 — เพิ่มทุกสัญญาณของ design**

คลิกขวาที่ชื่อ top-level ในหน้าต่าง Structure (sim)
แล้วเลือก **Add Wave**

**วิธีที่ 2 — เพิ่มทีละสัญญาณ**

คลิกขวาที่สัญญาณที่ต้องการในหน้าต่าง Structure หรือ Objects
แล้วเลือก **Add Wave**

**วิธีที่ 3 — พิมพ์คำสั่ง**

```text
add wave -r /*            # เพิ่มทุกสัญญาณในทุกระดับ
add wave tb_counter_tut/cnt   # เพิ่มสัญญาณเดียว
add wave -r /tb_counter_tut/*  # เพิ่มทุกสัญญาณใต้ instance นั้น
```

| ส่วน | ความหมาย |
|---|---|
| `-r` | ทำซ้ำลงไปในทุกระดับของ hierarchy |
| `/*` | ทุกอย่างใน scope ปัจจุบัน |
| `/tb_xxx/*` | ทุกอย่างใต้ instance ที่ระบุ |

### 1.3 เมื่อสัญญาณไม่ปรากฏ

> ถ้าเพิ่มสัญญาณแล้วไม่เห็น ให้ตรวจสอบตามลำดับนี้
> 1. เพิ่ม `+acc` ตอนโหลด design — เพราะการ optimize อาจตัดสัญญาณทิ้ง
> 2. ตรวจว่าสัญญาณนั้นถูกประกาศจริง ไม่ใช่ตัวแปรภายใน process ที่หายไปเมื่อ process จบ
> 3. ตรวจว่าเลื่อนเวลาไปแล้วหรือยัง ถ้ายังไม่เดินเวลาก็ยังไม่มีค่าให้ดู

## 2. การจัดกลุ่มสัญญาณ

เมื่อมีสัญญาณหลายสิบตัว ให้จัดกลุ่มเพื่อให้หน้าต่าง Wave อ่านง่าย

| คำสั่ง | ผล |
|---|---|
| `add wave -group <ชื่อ> <สัญญาณ>` | เพิ่มสัญญาณลงกลุ่ม |
| `add wave -divider <ชื่อ>` | แทรกเส้นคั่นระหว่างกลุ่ม |
| `add wave -radix hex <สัญญาณ>` | เพิ่มสัญญาณพร้อมกำหนดรูปแบบแสดงผล |

การจัดกลุ่มที่แนะนำสำหรับโค้ด VHDL ของคอร์สนี้

```text
add wave -group clock   tb_counter_tut/clk
add wave -group reset   tb_counter_tut/rst_n
add wave -group input   tb_counter_tut/en
add wave -group output  tb_counter_tut/cnt
add wave -divider ---
```

## 3. เลื่อนดูและซูม

| การทำ | วิธี |
|---|---|
| เลื่อนแนวตั้ง | ลากแถบเลื่อนด้านขวา หรือใช้ล้อเมาส์ |
| ซูมเข้า/ออก | ล้อเมาส์หรือกด **Zoom In** / **Zoom Out** |
| ซูมเข้าทั้งหน้าต่าง | **Zoom Full** |
| ซูมให้เต็มความกว้าง | **Zoom Full Width** |
| ซูมไปยังช่วงเวลาที่เลือก | เลือกช่วงเวลาแล้วกด **Zoom Selected** |

> เมื่อ waveform แน่นเกินไปจะอ่านยาก
> ให้ซูมเข้าเฉพาะช่วงเวลาที่สงสัย แทนที่จะพยายามอ่านทั้งหน้าต่าง

## 4. Cursor และการวัดเวลา

### 4.1 ใช้ cursor

ลากเส้น cursor ในหน้าต่าง Wave หรือคลิกขวาที่เวลาตำแหน่งใด
แล้วเลือก **Insert Cursor** หรือกด **Ctrl+F5**

เมื่อมี cursor แล้ว ค่าของสัญญาณทุกตัวที่แสดงอยู่จะเปลี่ยนเป็น
ค่า ณ เวลาของ cursor

### 4.2 วัดความต่างของเวลา

คลิกขวาที่หน้าต่าง Wave แล้วเลือก **Measure Selected** หรือพิมพ์

```text
measure time 55ns 46ns
```

ผลที่ต้องเห็นคือระยะเวลาระหว่างสองจุด

### 4.3 ใช้ประโยชน์จากตัวอย่างจริง

ตัวอย่าง `ex00_counter_tutorial` มีนาฬิกา period 10 ns
ถ้าวัดระยะเวลาระหว่างขอบนาฬิกาสองครั้ง ต้องได้ 10 ns

```text
# วัดจากขอบนาฬิกาที่ 5 ns ไปถึงขอบนาฬิกาที่ 15 ns
measure time 15ns 5ns
```

> ถ้าได้ค่าที่ไม่ใช่ 10 ns แปลว่าโค้ดไม่ได้ทำงานตามที่คาด
> ให้ตรวจที่ period ใน testbench

## 5. รูปแบบการแสดงผลของค่า

### 5.1 ระบบฐาน

| ระบบ | ตัวอย่าง |
|---|---|
| **Binary** | `0000_0101` |
| **Octal** | `05` |
| **Hex** | `05` |
| **Decimal** | `5` |
| **ASCII** | `ENQ` |
| **Time** | `5 ns` |
| **Real** | `5.00` |

คำสั่ง

```text
radix hexadecimal
radix -hex tb_counter_tut/cnt
examine -radix hex tb_counter_tut/cnt
```

ตั้งค่าเริ่มต้นของหน้าต่าง Wave ได้ที่เมนู **Wave → Edit Properties → Radix**

### 5.2 การจัดกลุ่มบิต

เมื่อต้องการดูบิตเฉพาะบางส่วน เช่น carry flag

```text
add wave -radix binary tb_counter_tut/cnt
```

ในหน้าต่าง Wave คลิกขวาที่สัญญาณแล้วเลือก **Data Format → Bit Order**
เพื่อสลับลำดับบิต และ **Radix → Radix** เพื่อเปลี่ยนฐาน

### 5.3 สิ่งที่ต้องระวังเมื่ออ่านค่า

> สัญญาณที่เป็น `std_logic_vector` อาจแสดงค่า `X` หรือ `U` ในตอนเริ่ม
> นี่ไม่ใช่บั๊ก แต่เป็นสถานะที่ถูกต้องของ VHDL ก่อนที่จะมี driver ให้ค่า
> และก่อน reset ทำงาน

## 6. ค่าพิเศษของสัญญาณ VHDL

สัญญาณชนิด `std_logic` มีค่ามากกว่า 0 และ 1 เสมอไป

| ค่า | ชื่อ | ความหมาย | รูปใน waveform |
|---|---|---|---|
| `0` | — | ตรรกะ 0 | เส้นล่าง |
| `1` | — | ตรรกะ 1 | เส้นบน |
| `U` | Uninitialized | ยังไม่เคยถูกกำหนดค่า | ตัวอักษร U |
| `X` | Forcing Unknown | ค่าที่ขัดแย้งกัน เช่น ขับ 0 และ 1 พร้อมกัน | กล่องเต็ม |
| `Z` | High Impedance | สถานะความต้านทานสูง | เส้นกลาง |
| `W` | Weak Unknown | ค่าที่อ่อนแอและขัดแย้งกัน | ตัวอักษร W |
| `L` | Weak 0 | ค่า 0 ที่อ่อนแอ | ตัวอักษร L |
| `H` | Weak 1 | ค่า 1 ที่อ่อนแอ | ตัวอักษร H |
| `-` | Don't Care | ไม่สนใจค่า | เส้นประ |

### 6.1 วิธีตรวจว่าค่า X เกิดจากอะไร

1. ดูว่าค่า X เริ่มต้นที่เวลาใด — ถ้าเริ่มที่ศูนย์แล้วหายเมื่อ reset ทำงาน
   แปลว่าเป็นพฤติกรรมปกติของการยังไม่มี driver
2. ถ้าค่า X โผล่ขึ้นกลางการทำงาน แปลว่ามีการขับสัญญาณพร้อมกันสองที่
   หรืออ่านค่าสัญญาณที่ยังไม่เคยถูกกำหนดค่า
3. ดูโครงสร้างของ design เพื่อหาว่าสัญญาณนั้นมี driver กี่ตัว

> ใน testbench ที่ดีจะตรวจค่า X ก่อนแปลงค่าเป็นตัวเลข
> เพราะ `to_integer(unsigned(sig))` จะทำให้โปรแกรมหยุดทันที
> ทำให้ไม่เห็นว่าปัญหาอยู่ตรงไหน

## 7. การบันทึกและเปิดดู WLF

### 7.1 ไฟล์ WLF คืออะไร

WLF คือรูปแบบไฟล์ข้อมูล waveform ของ Questa เก็บทั้งค่าของสัญญาณ
และข้อมูลการจำลอง ทำให้เปิดดูย้อนหลังได้โดยไม่ต้องรันซ้ำ

### 7.2 บันทึก

```bash
vsim -wlf counter.wlf -do "do ../../tcl/ex00_counter_tutorial.do" work.tb_counter_tut
```

หรือในโหมด GUI เลือก **File → Export → WLF**

### 7.3 เปิดดูไฟล์ WLF ที่บันทึกไว้

```bash
vsim -view counter.wlf
```

หรือในโหมด GUI เลือก **File → Open** แล้วเลือกไฟล์ `.wlf`
แล้วเปิดหน้าต่าง **WLF Wave** จากเมนู View

### 7.4 เก็บข้อมูลให้น้อยลง

ถ้าไฟล์ WLF ใหญ่เกินไป ให้จำกัดช่วงเวลาที่บันทึก

```text
log -w /tb_counter_tut/cnt {50ns - 200ns}
```

คำสั่ง `log` ควบคุมการบันทึกค่าของสัญญาณลงใน WLF
โดยไม่มี `log` เครื่องมือจะไม่บันทึกค่าของสัญญาณลงในไฟล์ WLF เลย

## 8. การเปรียบเทียบ waveform

เมื่อต้องการเทียบผลการจำลองสองชุด เช่น ก่อนและหลังแก้โค้ด

1. บันทึกแต่ละชุดเป็นไฟล์ WLF แยกกัน
2. เปิดหน้าต่าง **Wave** แล้วเลือก **Wave → Compare**
3. เลือกไฟล์ WLF ทั้งสองที่ต้องการเทียบ

หน้าต่างเปรียบเทียบจะแสดงความต่างของแต่ละสัญญาณเป็นสี

> การเปรียบเทียบ waveform เป็นวิธีที่มีประสิทธิภาพมากในการหาว่า
> การแก้โค้ดทำให้พฤติกรรมเปลี่ยนตรงจุดใด
> โดยเฉพาะเมื่อเปรียบเทียบกับ implementation อ้างอิง

## 9. การดูและกำหนดค่า memory

สำหรับ design ที่มี memory เช่น RAM

```text
mem load -infile /tb_xxx/mem_array -radix hex my_mem
mem examine my_mem -address 0x10
mem change my_mem -address 0x10 -radix hex 0xABCD
```

| คำสั่ง | หน้าที่ |
|---|---|
| `mem load` | โหลดค่าลง memory จากไฟล์ |
| `mem examine` | ดูค่าใน memory ที่ตำแหน่งที่ระบุ |
| `mem change` | เปลี่ยนค่าใน memory |
| `mem list` | แสดงรายการ memory ทั้งหมด |

มีหน้าต่าง **Memory Editor** ให้ใช้งานแบบกราฟิกได้จากเมนู **Tools**

## แบบฝึกหัดท้ายบท

1. โหลด `ex00_counter_tutorial` แล้วเพิ่มสัญญาณ `clk` `rst_n` `en` `cnt`
   ลงหน้าต่าง Wave พร้อมแยกกลุ่ม
2. วัดระยะเวลาระหว่างขอบนาฬิกาสองครั้ง และเทียบกับ period 10 ns
3. เปลี่ยนรูปแบบการแสดงผลของ `cnt` เป็น hex แล้วดูค่าที่เวลา 45 ns
4. หาช่วงเวลาที่ `cnt` เป็น `X` แล้วอธิบายว่าเกิดจากอะไร
5. ตั้ง cursor ที่เวลา 35 ns แล้วบันทึกค่าของสัญญาณทั้งหมด
6. บันทึกเป็นไฟล์ WLF แล้วเปิดดูอีกครั้งในโหมด GUI

---

## คำถามท้ายบท

1. สวิตช์ `-r` ในคำสั่ง `add wave` มีผลอะไร
2. ทำไมค่า `X` ที่เกิดตอนเริ่ม simulation ไม่ถือว่าเป็นบั๊ก
3. สัญญาณ VHDL ที่เป็น `std_logic` มีค่าพิเศษอะไรบ้าง และแต่ละค่าแปลว่าอะไร
4. การวัดเวลาด้วย `measure` ทำอย่างไร และใช้ตรวจอะไรได้
5. ไฟล์ WLF ต่างจากไฟล์ VCD อย่างไร และมีข้อดีอะไร
