ภาคนำ

คู่มือนี้คืออะไร

คู่มือนี้สอน การจำลองระดับ gate (Gate-Level Simulation, GLS) ด้วย QuestaSim / ModelSim ตั้งแต่พื้นฐานจนถึงระดับที่เอาไปใช้ต่อในงานจริงได้ แยกเป็น 8 lab แบบทีละขั้น ที่ทำตามแล้วรันได้จริงทุกขั้น

จุดต่างของคู่มือนี้คือ ตัวเลขและข้อความทุกตัวมาจากการรันจริงบนเครื่อง ไม่ใช่ตัวอย่างที่แต่งขึ้น — ทำซ้ำตามคู่มือแล้วจะได้ผลชุดเดียวกัน

จุดต่างสำคัญของฉบับนี้: RTL เขียนด้วย VHDL

โค้ดทั้งหมดในคู่มือนี้เริ่มต้นจาก VHDL ทั้งหมด

RTL (VHDL)  --ghdl synth-->  Verilog  --Yosys+Liberty-->  gate netlist (Verilog)
     |                                                              |
     +--------------- testbench VHDL ชุดเดียวกัน --------------------+

นี่คือสถานการณ์ที่พบบ่อยที่สุดในอุตสาหกรรม ASIC จริง: RTL เขียนด้วย VHDL แต่สังเคราะห์และจำลองระดับ gate ด้วย Verilog เครื่องมือที่ต้องใช้จึงมีทั้งสองภาษา

คู่มือนี้จึงต้องสอนเรื่องที่หลายคู่มือข้ามไป คือ การทำให้ testbench VHDL ชุดเดียว ขับได้ทั้งระดับ RTL (VHDL) และระดับ gate (Verilog) — ซึ่งเป็นหัวใจของ LAB 01 ถึง LAB 05

ผู้เรียนจะได้อะไร

เมื่อทำครบทุก lab ผู้เรียนจะทำสิ่งเหล่านี้ได้ด้วยตัวเอง

  1. เขียน RTL ภาษา VHDL และแปลงเป็น Verilog ด้วย ghdl synth แล้วสังเคราะห์ต่อเป็น gate netlist ด้วย Yosys + Liberty ของ IHP SG13G2
  2. ใช้ testbench VHDL ชุดเดียวกัน ขับทั้งระดับ RTL และระดับ gate โดยเปลี่ยนแค่ไฟล์ที่คอมไพล์เข้าไลบรารี work
  3. อธิบายได้ว่า RTL simulation กับ gate level simulation ต่างกันอย่างไร และอะไรที่ gate level จับได้แต่ RTL จับไม่ได้
  4. อ่าน เซลล์มาตรฐาน ของ SG13G2 และเข้าใจว่า Liberty, Verilog model และ timing check ของแต่ละเซลล์เป็นอย่างไร
  5. จับ บั๊กใน netlist ที่การจำลองระดับ RTL มองไม่เห็น
  6. สร้าง regression ของการจำลองระดับ gate ที่รันซ้ำได้และรหัสจบนำไปใช้กับ CI ได้

labNN_xxx/

ข้อตกลงเบื้องต้น

  • ต้องมี QuestaSim หรือ ModelSim 2026.1 (วิธีติดตั้งและ license อยู่ในหัวข้อ 1.2)
  • ต้องมี IHP SG13G2 (ไฟล์ Verilog model และ Liberty อยู่ใน cells/ แล้ว ไม่ต้องติดตั้งอะไรเพิ่ม)
  • Yosys และ GHDL ใช้เฉพาะตอนสังเคราะห์ netlist ใหม่ และต้องรันใน WSL (หัวข้อ 2.2) netlist ที่สังเคราะห์ไว้แล้วอยู่ใน netlist/ ของคู่มือนี้ ดังนั้น ทุก lab ที่เป็นการจำลอง รันได้บน Windows ล้วน ๆ
  • ถ้าไม่มี ModelSim เลย ยังตรวจโค้ด VHDL ทั้งหมดได้ด้วย GHDL (ภาคผนวก C)

1.2 ⚠ เรื่องใบอนุญาต (license) — อ่านให้เข้าใจก่อนทำ lab

ใบอนุญาตของเครื่องนี้เป็น node-locked แบบ session เดียว คือ จำลองได้ทีละ session เท่านั้น

ถ้ามี QuestaSim GUI เปิดค้างอยู่ (vish.exe -gui) มันจะถือ seat ของชุด QuestaSim การรันแบบบรรทัดคำสั่งด้วยชุดนั้นจะถูกปฏิเสธว่า

** Error: License checkout has been disallowed because
only one session is allowed to run on an uncounted nodelocked
license and an instance of QuestaSim is already running with a
nodelocked license on this machine.

แต่ ModelSim DE-64 ยังรันได้ตามปกติ เพราะเป็นอีก seat หนึ่ง

ทางแก้ที่คู่มือนี้ใช้: ไม่ hardcode path ของชุดติดตั้งเลย แต่ให้ tools/pick_tool.cmd ไล่ทดสอบ license จริงของแต่ละชุด (คอมไพล์ design จิ๋วแล้วโหลดจริง — เพราะ license ถูกเช็คตอน "โหลด design" เท่านั้น) แล้วเลือกชุดแรกที่ใช้ได้

ผลที่วัดได้จริงขณะที่ QuestaSim GUI ยังเปิดค้างอยู่

 tool   : C:\Siemens\modelsim_dlx64_2026.1\win64pe

ถ้าอยากบังคับให้ใช้ชุดใดชุดหนึ่ง ให้ตั้ง QUESTASIM_HOME หรือ MODELSIM_HOME

วิธีแก้คือ ประกาศ DUT เป็น component แทน entity แล้วปล่อยให้ ModelSim ทำ default binding ซึ่งจะผูก component ที่มีชื่อเดียวกัน เข้ากับ design unit ที่ชื่อนั้นในไลบรารี work ไม่ว่าจะเป็น VHDL entity หรือ Verilog module

tb/tb_cnt4.vhd (ตัดเฉพาะส่วนสำคัญ)

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity tb_cnt4 is
  generic (
    TRACEFILE  : string  := "trace.txt";
    RESULTFILE : string  := "result.txt";
    GATE       : boolean := false
  );
end entity tb_cnt4;

architecture sim of tb_cnt4 is
  constant CYCLE : time := 10 ns;

  signal clk   : std_logic := '0';
  signal rst_n : std_logic := '0';
  signal en    : std_logic := '1';
  signal q     : std_logic_vector(3 downto 0);

  -- ประกาศเป็น COMPONENT ไม่ใช่ entity work.cnt4
  component cnt4 is
    port (
      clk   : in  std_logic;
      rst_n : in  std_logic;
      en    : in  std_logic;
      q     : out std_logic_vector(3 downto 0)
    );
  end component cnt4;
begin
  clk <= not clk after CYCLE / 2;

  dut : cnt4
    port map (
      clk   => clk,
      rst_n => rst_n,
      en    => en,
      q     => q
    );
  -- ... ส่วน stimulus ...
end architecture sim;

  3. ถ้าชื่อไม่ตรง จะได้ข้อความ error ที่ชัดเจน ตอนคอมไพล์ ไม่ใช่ error ลอย ๆ ตอนโหลด design

บทเรียนที่ควรจำ: ชื่อ entity และชื่อ module ต้องตรงกัน นี่คือเหตุผลที่ rtl/*.vhd และ netlist/*_net.v ต้องตั้งชื่อให้เหมือนกันทุกตัวอักษร

1.8 กฎการผสม VHDL กับ Verilog (วัดแล้วพลาดได้จริง)

  1. ชื่อ entity/module ต้องตรงกันทุกตัวอักษรและเป็นตัวพิมพ์เล็กทั้งหมด Verilog เป็น case-sensitive และ VHDL ก็ case-sensitive เช่นกัน ชื่อ fsm_light ต้องตรงกันจริง ๆ ไม่ใช่ FSM_Light หรือ fsm_Light

  2. ชื่อ port ต้องตรงกันและเป็นตัวพิมพ์เล็ก เมื่อ GHDL แปลง VHDL เป็น Verilog มันจะ แปลงชื่อ port ทั้งหมดเป็นตัวพิมพ์เล็ก ดังนั้น rst_n ต้องเป็น rst_n ไม่ใช่ RST_N แม้ในไฟล์ VHDL จะเขียนตัวใหญ่ก็ได้

  3. ชนิดของ port ต้องเข้ากันได้ std_logic_vector ↔︎ Verilog [3:0] ผสมกันได้ แต่ unsigned ต้องแปลงเป็น std_logic_vector ก่อนออกจาก entity

  4. numeric_std ไม่มี std_logic_vector + integer ต้องใช้ unsigned หรือ unsigned_vector ภายใน แล้วค่อยแปลงกลับที่ port

  5. ค่าเริ่มต้นของ signal ต้องเป็น := ใน declaration signal clk : std_logic := '0'; — ถ้าไม่ใส่ := '0' นาฬิกาจะเริ่มเป็น 'U' และ not 'U' ก็ยังเป็น 'U' → นาฬิกาจะไม่เดินเลย ตลอดการจำลอง

  6. trim และ time'image ไม่มีใน GHDL VHDL-2008 integer'image(5) จะพิมพ์ " 5" (มีช่องว่างนำหน้า) ต้องตัดออก time'image จะพิมพ์หน่วยตาม resolution ของตัวจำลอง ซึ่งต่างกันระหว่าง ModelSim กับ GHDL คู่มือนี้มี helper nospace() และ timestr() ใน testbench ทุกไฟล์เพื่อแก้ปัญหานี้

  7. VHDL ใช้ wait until rising_edge(clk) ไม่ได้ถ้า clock เป็น 'U' ต้องประกาศ signal clk : std_logic := '0'; เสมอ (ข้อ 5)

1.9 ⚠ ข้อผิดพลาดที่ต้องรู้ก่อนเริ่ม: vsim-3693

ถ้าคอมไพล์เซลล์ Verilog ของ SG13G2 แล้วโหลด design โดยไม่ใส่ -t 10ps จะได้ข้อความนี้

** Fatal: (vsim-3693) The minimum time resolution limit (10ps)
in the Verilog source is smaller than the one chosen for SystemC or VHDL
units in the design. Use the vsim -t option to set the resolution.

สาเหตุ: โมเดลเซลล์ของ SG13G2 ประกาศ timescale 1ns/10ps แต่ค่าเริ่มต้นของ ModelSim คือ 1 ps ซึ่งละเอียดกว่า 10 ps ModelSim จึงห้ามและให้เลือก resolution ที่หยาบพอ

ผลที่ได้คือ Verilog 30 บรรทัด (วัดได้จริง) ดูไฟล์เต็มได้ที่ netlist/vhdl2verilog/cnt4_rtl.v

module cnt4
  (input  clk,
   input  rst_n,
   input  en,
   output [3:0] q);
  reg [3:0] cq;
  wire n4_o;
  wire [3:0] n7_o;
  wire [3:0] n13_o;
  reg [3:0] n14_q;
  assign q = cq; //(module output)
  /* rtl/cnt4.vhd:18:10  */
  always @*
    cq = n14_q; // (isignal)
  initial
    cq = 4'b0000;
  /* rtl/cnt4.vhd:23:14  */
  assign n4_o = ~rst_n;
  /* rtl/cnt4.vhd:27:18  */
  assign n7_o = cq + 4'b0001;
  /* rtl/cnt4.vhd:25:5  */
  assign n13_o = en ? n7_o : cq;
  /* rtl/cnt4.vhd:25:5  */
  always @(posedge clk or posedge n4_o)
    if (n4_o)
      n14_q <= 4'b0000;
    else
      n14_q <= n13_o;
endmodule

สังเกตสิ่งที่น่าสนใจมากในบรรทัดนี้

assign n13_o = en ? n7_o : cq;

นี่คือจุดที่ semantics ของ VHDL กับ Verilog ต่างกันอย่างมีนัยสำคัญ และเป็นแก่นของ LAB 06

VHDL ต้นฉบับ Verilog ที่ GHDL สร้าง
เงื่อนไข if en = '1' then en ? n7_o : cq
en = 'X' 'X' = '1' → false → ทำ else (คงค่าเดิม) ?: → propagate X → ผลเป็น X
en = '0' false → else false → else

คู่มือนี้จะพิสูจน์ความต่างนี้ด้วยการรันจริงใน LAB 06

proc gls_diff_lines {file_a file_b} {
    set a [split [gls_read_file $file_a] "\n"]
    set b [split [gls_read_file $file_b] "\n"]
    set diff {}
    set n [expr {[llength $a] > [llength $b] ? [llength $a] : [llength $b]}]
    for {set i 0} {$i < $n} {incr i} {
        set la [lindex $a $i]
        set lb [lindex $b $i]
        if {$la ne $lb} { lappend diff [list $i $la $lb] }
    }
    return $diff
}

บทที่ 8 — LAB 06: การแพร่ของค่า x

เป้าหมาย

พิสูจน์เรื่องที่สำคัญที่สุดของ GLS: RTL กับ gate level ให้คำตอบไม่เหมือนกันเมื่ออินพุตมีค่า x

เรื่องที่เกิดขึ้น

ทั้งสองระดับได้ netlist จาก โค้ดชุดเดียวกัน แต่มีความหมายของ x ต่างกัน

ฝั่ง RTL (VHDL)

elsif rising_edge(clk) then
  if en = '1' then
    cq <= cq + 1;
  end if;
end process;

  • ใน VHDL ตัวดำเนินการ 'X' = '1' ให้ผลเป็น false
  • จึงเข้าไปใน else → ไม่ทำอะไร → คงค่าเดิม

ฝั่ง gate (Verilog ที่ GHDL สร้าง)

assign n13_o = en ? n7_o : cq;

เมื่อ en = 'X':

  • ใน Verilog ตัวดำเนินการ ?: propagate ค่า x
  • ผลคือ n13_o = 'X' → D ของ flip-flop เป็น X → ฟลิป-flopจับ X

เพราะ Yosys pass fsm แปลง FSM แบบ binary เป็น one-hot โดยอัตโนมัติ
