# คู่มือ Siemens Precision Synthesis Quick Start (ฉบับเต็ม, ภาษาไทย)

เอกสารประกอบการอบรม **Siemens Precision Synthesis (PS)** สำหรับวิศวกรและนักศึกษาสายอิเล็กทรอนิกส์
โดยยึดลำดับงานจาก **Precision Synthesis Quick Start Guide รุ่น PS2018.1** และขยายเป็นแบบฝึกหัด (Lab)
บนบอร์ด **Digilent Nexys A7-100T** ตั้งแต่สร้าง RTL จนได้ bitstream

> คู่มือฉบับนี้เขียนสำหรับ **การอบรมในห้องเรียน** ทุกบทมีแบบฝึกหัดที่ทำต่อเนื่องกันได้
> โดยใช้ RTL ชุดเดียวกันตลอดคู่มือ ผู้เรียนจึงเห็นวงจรจริงตั้งแต่โค้ดจนถึงชิป

---

## 1. กลุ่มผู้อ่านและสิ่งที่ต้องรู้มาก่อน

| กลุ่ม | ต้องมีพื้นฐาน |
|---|---|
| นักศึกษาปี 3–4 สาย EE/CE | ดิจิทัลและตรรกะ, Verilog ระดับพื้นฐาน, พื้นฐาน MOSFET |
| นักศึกษาปี 5–7 / ผู้สนใจทำดีไซน์ชิป | ผ่านบทที่ 1–2 มาก่อน หรือเคยทำโปรเจกต์ FPGA มาแล้ว |
| ผู้สอน / ผู้ช่วยสอน | ใช้เป็นลำดับหัวข้อและ checklist การจัดปฏิบัติการ |

**เครื่องมือที่ต้องใช้**

| ขั้นตอน | เครื่องมือ | หมายเหตุ |
|---|---|---|
| เขียน/ตรวจ RTL | Precision Synthesis (Siemens EDA) | เป็นเครื่องมือหลักของคู่มือนี้ |
| จำลอง RTL | QuestaSim หรือ ModelSim (Siemens) | ต้องใช้ VHDL-2008 |
| จำลองแบบเสริม | GHDL (โอเพนซอร์ส) | ใช้ตรวจ testbench ได้ฟรี ดูบทที่ 1 |
| วางวาง/เดินสาย/สร้าง bitstream | AMD Vivado (เวอร์ชันที่รองรับ Artix-7) | ใช้รับเน็ตลิสต์ EDIF จาก Precision |
| โปรแกรมลงบอร์ด | Vivado Hardware Manager / openFPGALoader | ทดสอบบนฮาร์ดแวร์จริง |

> **หมายเหตุเรื่องตัวเลขในคู่มือ**
> ตัวเลขผลลัพธ์ของเครื่องมือในคู่มือเป็น **ตัวอย่างประกอบการอธิบาย** ไม่ใช่ผลจากการรันจริง
> เพราะตัวเลขขึ้นกับรุ่นของซอฟต์แวร์ ค่าคอนฟิก และเวอร์ชันไลบรารี
> ผู้เรียนต้องรันเองแล้วเทียบกับผลของตัวเองในตารางบันทึกผล (labs/results/)
> คำสั่งที่ขึ้นกับรุ่นจะกำกับไว้ด้วยคำว่า *(ตรวจสอบกับเอกสารของรุ่นที่ใช้)*

## 2. แผนที่จากคู่มือ PS2018.1 สู่คู่มือฉบับนี้

คู่มือต้นฉบับของซีเมนส์แบ่งการทำงานไว้ 3 ขั้นตอนหลัก คู่มือฉบับนี้ยึดโครงเดียวกันทุกจุด
เพิ่มรายละเอียดระดับที่ทำตามได้จริง และเพิ่มแล็บที่ตรวจสอบผลได้

| ขั้นที่ใน PS2018.1 | รายละเอียดในคู่มือต้นฉบับ | บทในคู่มือฉบับนี้ | ผลลัพธ์ที่ต้องได้ |
|---|---|---|---|
| **1. Set-Up Precision** | a. Create project | บทที่ 2 | โปรเจกต์ Precision ที่มี RTL และ SDC ครบ |
| | b. Add design source files (VHDL, Verilog, EDIF, SDC) | บทที่ 1–2 | RTL + testbench ที่ผ่านการจำลองแล้ว |
| | c. Select device | บทที่ 2 | เลือก XC7A100T-1CSG324 พร้อมไลบรารีของอุปกรณ์ |
| | d. Set Frequency | บทที่ 2 | SDC ที่มี `create_clock` 10 ns และหน่วง I/O ครบ |
| **2. Run Synthesis** | a. Compile | บทที่ 2 | ผ่านการตรวจ syntax และการเชื่อมต่อโมดูล |
| | b. Synthesize | บทที่ 2 | เน็ตลิสต์ + รายงานเวลา/พื้นที่ |
| **3. Analyze and Place & Route** | a. Report timing / View critical path schematics / Trace components from schematics to HDL sources | บทที่ 3 | อ่าน slack, utilization, unconstrained และย้อนกลับไป HDL ได้ |
| | b. Run integrated Place and Route in Precision and review reports | บทที่ 4 | ส่งต่อ Vivado ด้วย EDIF/XDC/Tcl และผ่านเกณฑ์ sign-off |

## 5. วิธีใช้คู่มือนี้

1. **อ่านตามลำดับบท** แต่ละบทจบด้วยแบบฝึกหัดที่ต้องผ่านก่อนไปบทถัดไป
2. **ทำแล็บต่อเนื่องกัน** ใช้ RTL ชุดเดียวกันตลอด เพื่อให้เห็นผลของการเปลี่ยนแต่ละขั้น
3. **บันทึกผลทุกครั้ง** ลงในตาราง `labs/results/qor_results_template.md` เพราะบทที่ 5 ต้องใช้ตัวเลขของตัวเอง
4. **เขียนข้อสรุปของแต่ละรอบ** ว่า "ได้ผลอย่างไร เพราะอะไร" ไม่ใช่แค่กรอกตัวเลข

### ข้อตกลงเรื่อง "ตัวเลขในคู่มือ"

ตัวเลขผลลัพธ์ของเครื่องมือในคู่มือเป็น **ตัวอย่างประกอบการอธิบาย** ไม่ใช่ผลจากการรันจริง
เพราะตัวเลขขึ้นกับรุ่นของซอฟต์แวร์และค่าคอนฟิก ผู้เรียนต้องรันเองแล้วเทียบกับตัวเอง
คำสั่งที่ขึ้นกับรุ่นจะกำกับไว้ด้วยว่า *(ตรวจสอบกับเอกสารของรุ่นที่ใช้)*

## 6. สิ่งที่ควรรู้ก่อนเริ่ม

1. **Precision เป็นเครื่องมือที่ต้องมีใบอนุญาต** หากโรงเรียนไม่มีสิทธิ์ใช้
   ให้ทำแล็บในบทที่ 1 และอ่านบทที่ 2–5 ในเชิง "ทำตามแล้วนำผลมาเทียบกัน"
   โดยใช้ตัวอย่างรายงานที่แนบไว้ในบท แล้วทำต่อใน Vivado จริง
2. **ชื่อเมนูและคำสั่งเปลี่ยนตามรุ่น** เอกสารอ้างอิง PS2018.1
   หากใช้รุ่นอื่นให้เทียบเมนูกับ Command Reference ของรุ่นนั้น
3. **สิ่งที่ไม่ควรทำ** อย่าเริ่มจากการกด Synthesize ทันทีที่ยังไม่ได้ตรวจ RTL
   และอย่าเชื่อตัวเลขเวลาจากขั้นสังเคราะห์ว่าเป็นคำตัด เพราะค่านี้ยังไม่รวมความหน่วงการเดินสาย
